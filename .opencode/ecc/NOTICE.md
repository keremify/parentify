# ECC attribution

Parts of this OpenCode setup are adapted from ECC (https://github.com/affaan-m/ECC),
MIT licensed. The upstream license is included in this directory.

Skills copied verbatim from ECC keep their upstream frontmatter, including
`metadata.origin: ECC`. Commands and agents were converted from ECC's
OpenCode adapter to OpenCode V2 formats, and some were adapted for this
project's stack.

ECC's plugin/hooks layer was intentionally not installed because it targets the
OpenCode V1 plugin API.
